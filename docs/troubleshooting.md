# Troubleshooting

| Symptom                                      | What to do                                                                                                                                                                                                                                            |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| App cannot find Node                         | Install Node 24+ or set an absolute executable path in Settings. Restart. The runtime is a child process, not a network service.                                                                                                                      |
| Runtime files missing                        | Run `bun install` and `bun run macos:build` from this checkout. The development `.app` depends on the checkout path.                                                                                                                                  |
| No projects after launching                  | Normal app uses `~/Movies/WinTheCloud Studio`; demo uses `.demo`. Run `bun run macos:demo`, or select the appropriate library in Settings and restart.                                                                                                |
| Import disabled                              | Save and approve the current script. Additional A-roll clips can be imported until planning starts.                                                                                                                                                   |
| Mock transcription disabled                  | Load a timestamped transcript first. Mock mode does not recognize speech; choose whisper (local) or OpenAI for real transcription.                                                                                                                    |
| Final Cut analysis not found                 | Run speech analysis in Final Cut first, then point **Import Final Cut Analysis…** (or `wts transcript fcp`) at the library, event, or media folder. Analyses map to clips by duration; identical-length retakes are fingerprinted with local whisper. |
| whisper transcription unavailable            | Install whisper.cpp (`brew install whisper-cpp`), download a ggml model, and set `WTS_WHISPER_MODEL` (default `~/.whisper-models/ggml-small.bin`). It is free and offline.                                                                            |
| Alignment misses sentences                   | Alignment is fuzzy matching over transcript words. Check that every recording has a word-level transcript and the script matches what was actually spoken; unmatched sentences are listed in the A-roll draft and can be bridged or revised manually. |
| OpenAI credentials missing                   | Save the key in Settings. It is stored in the login Keychain. Unlock Keychain if macOS requests it.                                                                                                                                                   |
| OpenAI model unavailable                     | Select a structured-output-capable model available to your API account. No model access is assumed from a ChatGPT subscription.                                                                                                                       |
| Transcription upload too large               | Use timestamped transcript import. The MVP compresses audio but does not split very long uploads.                                                                                                                                                     |
| Invalid transcript                           | Use ordered non-overlapping start/end seconds relative to the recording, with unique segment IDs. See the example JSON.                                                                                                                               |
| Invalid Director plan                        | Inspect the structured error. Timing, source bounds and template parameters must pass validation. Retry planning or revise the source; invalid output is never executed.                                                                              |
| Remotion fails                               | Read the scene job error/log. Check first-render browser download/network access, disk space and font/template parameters. `bun run test:integration` isolates rendering.                                                                             |
| FFmpeg encoder unavailable                   | Use a build with `libx264` and `libmp3lame`, and ensure ffprobe is also installed. Set `WTS_FFMPEG_PATH` / `WTS_FFPROBE_PATH` if needed.                                                                                                              |
| Build interrupted                            | Use **Recover Interrupted Work** in Production, or `bun run wts project recover <project-id>`, then retry. Recovery refuses a live owner. Verified completed assets are reused; the app does not silently resume work after launch.                   |
| Project already active                       | Wait for the other app/CLI operation or cancel it there. Avoid launching multiple app instances for the same project.                                                                                                                                 |
| Proposal is stale                            | Generate a new proposal against the current plan; the old proposal cannot overwrite newer decisions.                                                                                                                                                  |
| Build says approve storyboard                | Applying a patch or undo creates a new plan version and clears downstream approvals. Review and approve it first.                                                                                                                                     |
| Approved rough cut cannot rebuild            | Make a revision first. Gate 2 approval binds to the reviewed render.                                                                                                                                                                                  |
| Old preview after revision                   | The app keeps earlier renders visible with a warning until the new plan is approved and built.                                                                                                                                                        |
| Resolve API unavailable                      | Use the FCPXML export. The app does not change Resolve's external scripting/security preferences. See `docs/resolve.md`.                                                                                                                              |
| Resolve media offline after moving a project | Relink its `cache` and `assets/generated` files, or regenerate the export at the new location.                                                                                                                                                        |

Technical QA performs complete output decode, duration checks and source/asset validation. It also reports sustained silence and audio peak observations. These checks do not establish factual accuracy, perceptual quality, or creative approval. Inspect the rough cut and the QA JSON.

To back up, quit the app and any CLI jobs, then copy the complete library including `studio.sqlite` and project directories. Do not edit SQLite/project files behind an active runtime. No automatic cache cleanup or deletion is implemented.
