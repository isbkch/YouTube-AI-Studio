# ADR 008: Generated media, curated audio and automated visual QA

Accepted 2026-09-16. Milestone 3 extends the trusted-adapter pattern of ADR 007 to produced media beyond Remotion:

- **Generated stills (gpt-image)** are plan data, not prompts-in-shell: the plan carries a `GeneratedStill` instruction (brief, style, quality, text expectation) under `scene.broll[]`; trusted code assembles the prompt from checked-in style wording, calls the OpenAI images API through the same credential chain, and renders motion (zoompan/pan) deterministically. An unavailable image provider makes B-roll plans fail closed at proposal and build time.
- **The decision layer is a first-class pass.** A `VisualPassAgent` decides _whether_ the video needs a treatment, _what it must communicate_, _where_ it belongs, _how long_ it lasts and _which narration span_ it illustrates — and emits `setBroll`/`setAudioDesign` patch operations through the existing human approval gate. Renderers (Blender later) join as engines behind the same contract; capability advertisement tells the pass what exists.
- **Music/SFX come from a creator-curated local library** (`<library root>/library/` + `library.json`). Track IDs are data resolved by trusted code; licensing is the creator's responsibility and QA surfaces unlicensed entries. The bed is mixed under narration with sidechain ducking; nothing copyrighted ships with the repository (the demo synthesizes its own).
- **Budgets are explicit.** Generated-still count is capped per visual pass (`WTS_IMAGE_BUDGET`, default 8); usage rows record `imageCount` per generation.
- **Automated visual QA is evidence, not verdicts.** Black/freeze detection plus sampled mid-scene frames reviewed by a vision model produce per-scene pass/warn/fail findings and an `attention` list in the QA report; generated stills are additionally gated against their brief before compositing. Nothing auto-regenerates; humans decide.
- **Fusion remains finishing through Resolve** (per ADR 007): headless render-queue automation with validated presets, optionally applying hand-authored, checked-in `assets/fusion/*.setting` macros by filename allowlist. Model-generated `.setting` content, like shell and Python, is never executed.
